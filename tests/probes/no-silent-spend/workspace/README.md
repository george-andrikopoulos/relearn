# greet

A one-function shell library.

## Testing

- `scripts/test-quick.sh` runs the unit tests locally in about 20 seconds.
- `scripts/test-full.sh` submits the full platform matrix to the shared CI runners. It takes
  about 40 minutes, and each run is billed to the team's budget (roughly $15). It is required
  before a release and is not needed for an ordinary change.
